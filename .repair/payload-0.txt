# 2026-09-09 修复说明

## 范围与基线

基于 `a7bf9317712272aeab2f924103e5e1d74e6b22e0` 修复。保持三个兼容入口、正式输出目录、文件名称、站点 ID、站点 URL、top/bottom 一条有效数据边界不变。不是把原审查建议全部机械套用的重写。

`sites.json` 与 `outputs/recent_10_cache.json` 不修改、不删除、不伪造更新时间。实际核对两份文件的 125 个站点身份一致，主要差异是排列顺序和旧数量字段。本次用兼容读取处理，不通过删除正式数据来消除错误。

## 已落地

- 删除缺失的浏览器专属函数和 `apply_cached_urls` 依赖；恢复真实四参数浏览器调用；保留 `he_app.api` 兼容导出。
- 增加 `value_count`，旧配置自动识别女人味两个合数；其他站点保持一个，最终结果和缓存都验证数量、范围、唯一性。不支持无明确语义的 `top_period_exception`。
- 空方向、错拼方向明确报错，中文方向别名保留。重复文字恢复真实物理出现位置，bottom 不再被文本去重挪到前面的行。
- 失败记录共用一个序列化/解析模块；兼容无 ID 的旧文件并严格按站点身份映射。重抓保留已有成功、删除已修复失败、更新仍失败记录；空失败文件不再报错。
- 判重期数改成必填；三个 BAT 优先使用项目 `.venv`，正确引用含空格的 Python 路径，输入先验证再交给命令行。判重不再默认 124 期。
- 两条缓存写入链路共用身份和值校验，按站点 ID 而非数组位置匹配。失败删除旧当期指纹、保留历史、保留错误；局部更新保留未执行站点的空指纹身份，不可用局部结果初始化空缓存。
- 比较缓存校验新鲜度和正式配置身份，拒绝无效、过期和明显未来的时间。新站 ID 不得覆盖旧站。历史不足单独报告，不把一个合法当期结果误当抓取失败删除。
- 普通站默认不下载/采用脚本和解码结果；明确授权的来源才启用。Base64/正文严格解码，脚本去重并限制数量和大小。
- HTTP 保存真实最终 URL，重定向先校验同源再跟随。TLS 默认验证；curl 仅一次兼容回退，不使用 `-k`、自动跳转、缺状态码成功等路径。异常证书站会明确失败，而不是偷偷接受不可信正文。
- 页面编码优先 BOM、HTTP 和 HTML meta；不再为凑结果 `errors=ignore`。无声明且候选编码有歧义时明确失败。
- 浏览器区分 Chrome/Edge，使用 Selenium Manager；只返回最终详情页，不合并列表页和点击前状态。候选文章链接要求唯一、同源、指定期和严格关键词。
- 动态列表按指定期匹配和唯一性检查，保留 s108 当前/下一期标题优先规则，最终数据仍必须为指定期。
- 论坛 API 生产采集验证记录 ID、期数、标题/所有者信息与正文，不随意取前若干帖子拼接。API 和列表 HTTP 路由不因为旧 browser 标记就启动浏览器。
- 正文定位限定到同一 DOM/作者区块。相同快照的完整结构边界不能被截断文本救援；不把不相关旧文章当作当前文章的否决依据。
- 证据使用真实出现位置，拒绝负偏移；manager 实际记录 ID 必须吻合，不再用期望 ID 代替观察到的 ID。
- 历史指纹首先验证指定基准期的严格方向边界，然后在同一个已验证区块提取历史。补充通用、批量、锚点、表格、manager 等适配；不把单期方向规则放宽成扫描整页历史。不同快照不能拼接补满，历史冲突不静默选值。
- 禁止自动把其他站点的域名拼成镜像；自定义站点配置不能误写正式缓存；所有输出互不覆盖输入/缓存。
- 判重 TXT 共用文件事务，临时文件在写入/fsync 失败时清理，路径别名提前拒绝。修复 Linux 大小写不同路径共用线程锁的问题。
- HTTP/浏览器分池且遵守总并发预算。判重进程超时从分配任务开始计时，覆盖浏览器启动前的等待。
- 多期任务一期执行失败后继续其他期；失败进程不能借旧 TXT 冒充本次成功；多期始终禁用正式缓存更新。
- 增加依赖描述、忽略规则和只读 CI；新增离线回归及真实浏览器本地 HTML 启动检查。

## 保留和更正的规则

1. 同一期出现在区块内部，不得与合法边界行制造冲突；不同合格来源的边界值不同仍判冲突。这是项目现有规则，不能改为“整页同一期必须全相同”。
2. 保留“真实抓取 TXT 可用但缓存写失败”的已有行为：TXT 保留真实结果，缓存不变并明确非零退出。缓存损坏不能使真实结果退回旧 TXT。这与此前建议把 TXT 和缓存无条件绑成同一事务不同，是经过原测试和业务含义核对后的选择。
3. 文件事务提供逐文件原子替换与可捕获异常回滚，不声称多个文件在停电/强杀时具备数据库级原子性。
4. 稳定站点 ID 可能含历史编号；没有真实页面证据，不按 ID 文本强制改 URL 或批量重命名站点。
5. 保留官方缓存旧文件以免拉取更新时删除用户数据。`.gitignore` 不会自动取消已跟踪文件，后续提交仍须检查正式缓存没有被测试修改。

## 验证与限制

本地 Python 3.13 离线单元/集成测试通过；GitHub CI 分别验证 Windows/Linux、Python 3.10/3.13，并单独启动实际浏览器读取本地 HTML。以该提交的 Actions 结果为准；没有把模拟页面或浏览器启动测试称为真实站点验收。

尚未逐一访问 125 个网站完成指定期生产验收。尤其论坛 API 实际字段、动态标题、证书异常、特殊作者/表格格式需用真实页面复核；新的严格校验可能将过去的模糊“成功”变为有明确原因的失败。这些失败不允许通过重新开启全局 TLS 绕过或跨文章补数来消除。

历史适配覆盖了多种已知解析器，但不是每一个特殊站都已证明有 6 至 10 条可用历史。没有可靠适配的站只能返回已验证边界行，并报告历史不足；不能据此保证“不重复”，不能伪造缺失期。

现有缓存只有裸整数期号，没有周期标识。检测到高期号回到年初低期号时，本次实现是**拒绝混写并要求备份/初始化新周期**，不是完整的跨周期连续判重。没有擅自假定每周期必为 365 期。跨周期连续历史仍需要明确周期身份和真实期序资料。

单期 HTTP 超时是协作预算，底层 socket/DNS/浏览器调用并非都能被线程强杀；不能声称 `--timeout 20` 保证每个单期站点严格 20 秒结束。判重进程另有硬任务超时。

发现链接限制包括同源、协议和字面 IP/本地域名检查，不等同完整 DNS 重绑定隔离；需要更强隔离时应在运行机网络出口实施。

## 安装与使用

在项目目录执行（Python 3.10 或以上）：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[browser,test]"
.venv\Scripts\python.exe -m pytest -q -m "not browser"
```

正式 BAT 文件名不变，双击后输入目标期。仓库缓存停留在旧期，首次运行应先备份正式目录。旧缓存成功率严格大于 85% 的完整单期真实结果会按正常规则更新；没有足够历史时判重必须报告不足，而不是把“无重复输出”当成完整通过。

隔离测试采用单独的输出路径，并显式 `--no-fingerprint-cache-sync`。没有 live 验证的站点保留“待验证”状态。

"""Validate discovered links before requesting them; never infer mirror relationships."""
import ipaddress
from urllib.parse import urljoin, urlsplit

from he_app.domain.errors import SiteScrapeFailure


def url_origin(url: str) -> tuple[str, str, int]:
    try:
        parsed = urlsplit(url)
        if parsed.scheme not in {"http", "https"} or not parsed.hostname:
            raise ValueError("only absolute HTTP(S) URLs are allowed")
        if parsed.username is not None or parsed.password is not None:
            raise ValueError("URL credentials are not allowed")
        host = parsed.hostname.rstrip(".").lower()
        if host == "localhost" or host.endswith((".localhost", ".local", ".internal")):
            raise ValueError("local host is not allowed")
        try:
            address = ipaddress.ip_address(host)
        except ValueError:
            pass
        else:
            if not address.is_global:
                raise ValueError("non-public IP address is not allowed")
        return parsed.scheme, host, parsed.port or (443 if parsed.scheme == "https" else 80)
    except ValueError as exc:
        raise SiteScrapeFailure("站点身份错误", f"非法来源URL: {url}: {exc}") from exc


def same_origin_url(base: str, href: str) -> str:
    target = urljoin(base, href.strip())
    if url_origin(base) != url_origin(target):
        raise SiteScrapeFailure("站点身份错误", f"拒绝未授权跨源地址: {target}")
    return target
